# Активность и аудит

Все пять операций используют `kaiten_navigation_read`; общее число
инструментов остаётся равным 18. Полный JSON сохраняет исходные детали событий.

| Операция                           | Аргументы                                       | Результат                               |
| ---------------------------------- | ----------------------------------------------- | --------------------------------------- |
| `auditLogs.retrieveAuditLogEvents` | Необязательный `query`                          | `{result: events[]}`                    |
| `activity.listCompanyActivity`     | Необязательный `query`                          | `{result: {items, limit, next_cursor}}` |
| `activity.listSpaceActivity`       | `space_id`, необязательный `query`              | Такая же страница активности            |
| `activity.iterateCompanyActivity`  | Необязательные `query`, `max_items`             | `{result: {items, truncated}}`          |
| `activity.iterateSpaceActivity`    | `space_id`, необязательные `query`, `max_items` | Такой же ограниченный снимок            |

Фильтры активности: `limit`, непрозрачный `cursor`, строка `actions` через
запятую, `author_id`, `created_after`, `created_before`. Для компании также
доступен `card_id`. Передайте `next_cursor` как `cursor` следующего запроса
с теми же фильтрами; `null` завершает пагинацию. Курсоры передаются без изменений.

Итераторы используют публичный обход клиента и проверки метаданных/повторов.
`max_items` равен 100 по умолчанию, максимум — 1000. Для определения `truncated`
читается один дополнительный элемент, иногда с новой страницы. Снимок не
содержит токен продолжения; для возобновляемого экспорта используйте страницы.
Таймаут и отмена MCP действуют на весь обход.

Фильтры аудита: `from`, `to`, `author_id`, `author_uid`, строки `categories`
и `actions` через запятую, идентификатор события `id`, `limit` и `offset`.
Ответ — один исходный массив; смещение увеличивается явно. Строки дат
передаются в исходном виде и проверяются Kaiten. Сервер проверяет положительные
целые лимиты и неотрицательные целые смещения без придуманного ограничения
размера страницы. Доступ к журналам зависит от прав владельца токена и тарифа
Kaiten. HTTP-ошибки сохраняют статус без раскрытия приватного ответа.

```json
{
  "request": {
    "operation": "activity.listCompanyActivity",
    "args": {"query": {"card_id": 10, "limit": 25}}
  }
}
```
