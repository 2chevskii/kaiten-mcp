## Начните с рабочей задачи

После [подключения MCP-клиента](./guide.md) попросите ассистента:

> Найди мои просроченные карточки на доске «Поддержка».
>
> Прочитай эту карточку и комментарии, затем объясни, что блокирует работу.
>
> Создай карточку релиза и добавь чек-лист с этими тремя задачами.

MCP-клиент запускает локальный процесс и общается с ним через stdio. Сервер
отправляет запросы в Kaiten с правами вашего API-токена. Каждый сервер использует
одну компанию и один токен; изменения применяются при вызове инструмента.

Проблемы с подключением? Откройте [решение проблем](./troubleshooting.md).
Для участия в проекте начните с [руководства разработчика](./development.md).
