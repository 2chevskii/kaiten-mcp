# Учёт времени и отчёты

Эти [расширенные операции](./api.md) используют `kaiten_cards_read` и
`kaiten_cards_write`; сервер по-прежнему предоставляет 16 инструментов.
Полный JSON-ответ upstream, включая агрегаты отчётов, сохраняется в `{result}`.

| Операция                       | Аргументы                           | Поведение                                                                     |
| ------------------------------ | ----------------------------------- | ----------------------------------------------------------------------------- |
| `cardTimeLogs.addTimeLog`      | `card_id`, `body`                   | Запись времени: `role_id`, `time_spent`, `for_date`, необязательный `comment` |
| `cardTimeLogs.getTimeLogs`     | `card_id`, `for_date?`, `personal?` | Чтение ответа журнала карточки                                                |
| `cardTimeLogs.updateLogRecord` | `card_id`, `time_log_id`, `body`    | Изменение роли, минут, даты или комментария; требуется хотя бы одно поле      |
| `cardTimeLogs.removeTimeLog`   | `card_id`, `time_log_id`            | Удаление записи                                                               |
| `timesheet.getList`            | `query`                             | Фильтрация, группировка и пагинация отчётов                                   |

Kaiten записывает `time_spent` в минутах и использует `role_id: -1` для встроенной
роли Employee. ID пользовательских ролей остаются положительными безопасными
целыми. Аргументы чтения, изменения/удаления и замены роли также принимают этот
встроенный ID; допустимость операции проверяет Kaiten. См.
[официальный справочник отчётов](https://developers.kaiten.ru/timesheet/get-list).

Даты проверяются по календарю и используют `YYYY-MM-DD` без времени. Запрос
отчёта требует `from` и `to`; фильтры ID тегов, пользователей, групп, пространств,
досок, колонок, карточек и видимых колонок принимаются массивами или строками с
запятыми. Также доступны исходные параметры состояния, группировки,
единиц/точности времени, распределения по дням и общей суммы. Значения передаются
клиенту без преобразования; нули, false и пустые комментарии сохраняются.

Размер страницы отчёта — 1–200, `offset` выбирает следующие страницы. Исходный
JSON сохраняется, даже если группировка меняет форму ответа. У закреплённого
клиента метод `getTimeLogs` карточки не имеет параметров пагинации, а upstream
ограничивает ответ 100 записями. Для пагинации используйте `timesheet.getList`
с диапазоном дат и `card_ids`; MCP не обрезает исходный ответ и не придумывает
для него курсор.

Запись часа по роли Employee через `kaiten_cards_write`:

```json
{
  "request": {
    "operation": "cardTimeLogs.addTimeLog",
    "args": {
      "card_id": 10,
      "body": {
        "role_id": -1,
        "time_spent": 60,
        "for_date": "2026-11-06",
        "comment": "Investigation"
      }
    }
  }
}
```
